# UI audit: Go replacement

The audit found a missing UI, not just a few rendering differences. The Python `/admin` page and its HTTP API had no Go equivalent, even though the access store and MCP administration tools were present. The graph assets had been carried across, but the browser tests had not. Static-file checks and Go coverage did not catch either problem.

## Scope and method

The baseline is the retained Python implementation on `origin/python`, including `src/memento/admin/http.py`, its static assets, and `tests/browser/graph.spec.ts`. The audited Go base is `670543e`, plus the fixes accompanying this report. No production state, credentials, embedding jobs or configuration were changed.

`tools/browser/audit.mjs` starts `TestUIAuditServer` with a temporary repository and SQLite databases. It uses the real Go HTTP routing, managed access store, graph snapshots, detail/search/export handlers, and embedded UI. The fixture has 120 live concepts, one trashed concept, ready synthetic vectors, an administrator, and a projects-only reader. Fixture credentials are local test values, never production credentials.

Most browser checks use those real endpoints. Delayed responses, partial/failing requests, aggregate-only snapshots and refresh scheduling responses use explicitly intercepted requests. Large-graph pointer tests use 1,001 nodes in the real Three.js scene. This separates UI failure handling from model inference, which has its own model and worker tests.

## Findings and fixes

| Finding | Origin | Resolution |
|---|---|---|
| `/admin`, its static assets and every admin HTTP operation were absent | Go-port regression | Restored HTML/JS, API route ownership, managed-store auth, CRUD/credential operations, warning decoration and the 50-event activity list. Added handler, store-failure and real transport tests. |
| Points-mode picking/hover used `instanceId`, although Three.js Points returns `index` | Inherited graph bug | Both hit forms are supported. Browser tests pick and hover in 1,001-node mode. Empty-scene hits are also handled. |
| Releasing a pinch could select or deselect a node | Inherited graph bug | Multi-pointer gestures and cancellation cannot finish as a click. Pointer state is cleared on cancellation/lost capture. |
| Search, overview and link-navigation replies could overwrite a newer view | Inherited asynchronous-state gap | Added abort signals, request generations and a view epoch; simulation changes clear old graph/inspector state immediately. Delayed-response tests cover each path. |
| Inspector could remain in its loading state after a failed detail request | Existing graph behavior | Detail failures end loading and show an inspector error. |
| Overview navigation retained filters and obsolete inspector state | Existing graph behavior | Overview resets search/type/selection and cancels pending navigation. Trash/view changes use the same reset boundary. |
| Scene unmount leaked animation/listeners/overlays | Inherited lifecycle gap | Added scene disposal, animation cancellation, listener abortion, worker termination, DOM cleanup and renderer disposal. |
| PNG export depended on the previous WebGL drawing buffer; SVG/JSON blob URLs were not revoked | Inherited export gaps | PNG renders immediately before capture; downloaded blob URLs are revoked. |
| Preview-export checkbox had no server implementation | Inherited misleading control | Removed it. The dialog now states that SVG/JSON contain explicit concept links and metadata, without previews or semantic vectors. |
| Visible refresh could submit an empty selection from aggregate mode | Existing graph behavior | Disabled visible refresh for aggregate and empty views; full refresh retains confirmation. |
| Admin async actions could fail without visible feedback; locked pages retained old content and secret-dialog Escape retained credential text | Inherited admin gaps | Added caught action errors, session-generation checks, content/secret clearing on lock and secret clearing on dialog close. |

The restored admin page keeps the original managed-access boundary: `/admin*` returns 503 without a managed store; static pages do not reveal principal data; API requests require an explicit admin bearer and return 401 otherwise. The UI stores credentials only in tab memory. Tests verify that listing/activity omit plaintext credentials, rotation invalidates the previous credential, and lock prevents late responses from repopulating the page.

## Browser coverage

The repeatable audit checks:

* Real startup, direct graph rendering, type filters, every size metric, semantic toggle/opacity, force controls/reset, wheel zoom and tablet viewport.
* Inspector loading, explicit relationships, search navigation, tag filtering, deselection, overview reset, visibility simulation and trash inclusion.
* PNG/SVG/JSON downloads, node/settings payloads, export availability and object-URL cleanup.
* Aggregate rendering, cluster expansion/member lists, size-option transitions and aggregate refresh restrictions.
* Points-mode hover/picking, pinch/cancel behavior, empty scenes and scene disposal.
* Delayed overview/search/detail responses, failed detail loading, API failure/retry, and completed-refresh preservation of filters/semantic settings.
* Refresh selected/visible/full request shapes, confirmation cancellation, simulated-view restrictions, unavailable-worker feedback and error handling.
* Admin login/denial, presets/create, policy edit, rename, enable/disable, rotation, copy, revoke/delete, activity, secret close/Escape, storage absence, lock and stale-session responses.

Final local results: Chromium **17/17**, WebKit **17/17**, and Firefox **3 passed / 14 not run / 0 failed**. Chromium and WebKit run the graph and admin scenarios. Firefox is probed for WebGL2; unsupported graph cases are explicitly recorded as `not_run`, while admin and fallback-message checks run. Local headless Firefox had no WebGL2. The audit does not claim a Firefox graph pass or physical iPad/Safari certification; touch events and a tablet viewport were exercised in automation.

The clipboard is exercised through Chromium's browser permission API. WebKit/Firefox clipboard checks use a test shim because their automation permission support differs. Keyboard use of the forms/dialogs is covered incidentally; this is not a WCAG or screen-reader certification. Graph node selection remains pointer-oriented.

SVG/JSON retain the baseline bounded explicit-link export contract rather than being a serialization of the WebGL scene. Semantic overlays and current 3D camera transforms are represented by PNG, not SVG/JSON. No export-preview implementation is claimed.

## Reproduction and gates

```sh
cd tools/browser
npm ci
npx playwright install --with-deps chromium webkit
cd ../..
make ui-test
UI_BROWSER=webkit make ui-test
# Optional, with unsupported graph cases reported rather than hidden:
UI_BROWSER=firefox make ui-test
```

`PLAYWRIGHT_CHROMIUM_EXECUTABLE` can point at an already-installed Chromium binary. Reports, screenshots, downloads and fixture logs are written under `build/ui-audit/<engine>/`. The fixture binds an ephemeral localhost port and deletes its temporary repository on shutdown. It skips in ordinary `go test` runs unless the browser runner explicitly enables it.

CI installs the pinned Playwright package and runs Chromium and WebKit after `make audit`, retaining the reports as `ui-audit-results`. Local `make quality` retains 100% production Go statement coverage, including the restored admin handler. Race, fuzz, vulnerability, cross-build, model-independent performance, release archive and container/0.5.9 rollback checks passed during this audit.

The production deployment is unchanged. These results describe the tested source and disposable containers, not a post-deployment validation of the NAS.
