# UX feature inventory

`testdata/features/ux/` records the maintained browser behaviour of the graph debugger and access manager. `testdata/features/ux/scenario-inventory.json` is the machine-checked source for scenario IDs and evidence links. Run `make ux-check` to check those bindings; use [the browser reproduction instructions](../tools/browser/README.md) for the executable local/CI suite. `documented_only` means the behaviour ships today but has no direct browser or Go assertion. `partial` means surrounding assertions exist, but the full rendered behaviour is not checked end to end.
